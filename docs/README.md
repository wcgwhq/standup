# docs/

Briefs, specs, handoffs, formulas, sources and reference prototypes for this site. Drop them here and ask an agent to port them: scope into `intent.md`, brand into `design.md` and `src/styles/global.css`, numbers into `src/data/`, words into `src/i18n/`.

`decisions.md` is the running log every agent reads. Add one dated line per decision worth keeping.
